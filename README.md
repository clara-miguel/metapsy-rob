# Replication materials: Risk of bias in psychotherapy trials for depression

Data and R code to reproduce all analyses and tables in the manuscript "Risk of bias in psychotherapy trials for depression: a large-scale empirical examination using a structured assessment tool developed for psychotherapy research".

## Files

- `01_reproducible_analysis.R`: main script. Reproduces all results (Objectives 1–5 and the post-2001 sensitivity analyses).
- `irr_ratings.csv`: ratings from the inter-rater reliability subsample (237 trials).
- `analysis_data.csv`: effect sizes, risk of bias ratings and trial characteristics (514 trials, 941 effect sizes).
- `codebook.md`: description of all variables.
